# NodePulse 启动器

基于 **.NET 8 / Avalonia** 的《我的世界》Java 版第三方启动器。

## 功能特性

- 支持原版、Fabric、Forge、NeoForge、Quilt、OptiFine 全加载器
- 内置 Modrinth 模组 / 整合包 / 光影 / 资源包下载
- 集成陶瓦与 Linker 双联机方案
- 离线 / 外置 / 正版全账户支持
- 绿色便携，深色浅色随心切换

## 系统要求

- Windows 10+ / macOS 12+ / Linux
- .NET 8.0 运行时
